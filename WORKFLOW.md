# Workflow Git SimKlinik

## Tujuan

Mengelola perubahan kode dan menyimpan versi proyek menggunakan Git dan GitHub.

## Alur Kerja

1. `git status` — memeriksa perubahan file.
2. `git add .` — menyiapkan perubahan untuk disimpan.
3. `git commit -m "pesan perubahan"` — mencatat perubahan ke riwayat Git.
4. `git push` — mengirim perubahan ke repository GitHub.
5. Memeriksa repository GitHub untuk memastikan perubahan sudah terunggah.
